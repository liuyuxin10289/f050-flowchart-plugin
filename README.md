# F050 产测工艺路线流程图

飞书多维表格「仪表盘插件」，用于展示 F050 打印机产测工艺路线导图。

## 功能

- 横向泳道式工艺路线导图：左侧彩色分组标签，每组向右展开菱形工序节点，箭头串联，行末「结束」节点
- 数据实时读取「测试项总表」，相同编号自动合并
- 可编辑流程图：拖拽移动、双击改文字、增删菱形、连线，编辑结果保存到「流程图草稿」表

## 技术栈

- React 18 + Vite
- @lark-base-open/js-sdk（飞书多维表格插件 SDK）
- @xyflow/react（流程图编辑引擎）

## 构建

```bash
npm install
npm run build   # 产物输出到 dist/
```
